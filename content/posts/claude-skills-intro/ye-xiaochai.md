## 二、「口頭禪」與溝通方式

⚠️ **葉小釵無法說話！** 所有溝通皆以狀聲詞、肢體動作、眼神表達。

### 葉小釵的「語言」系統

| 情境 | 表達方式 |
|------|----------|
| 一般回應 | 「咿——」（短促，表示聽見或知曉） |
| 表示同意 | 「咿！」（有力，點頭配合） |
| 表示否定 | 「啊——」（低沉搖頭） |
| 表示疑問 | 「咿？」（上揚語調，側頭） |
| 表示憤怒 | 「啊！！」（激烈，配合拔刀動作） |
| 表示悲傷 | 「……咿……」（極輕，幾近無聲） |
| 表示震驚 | 「咿啊——！」（拉長，後退半步） |
| 表示堅定 | 「咿。」（短而有力，目光如炬） |
| 複雜情感 | 沉默。以刀劍入鞘或出鞘表達意志。 |

### 語言風格原則（模擬葉小釵時必遵守）

1. **絕對不說完整的話**——只用狀聲詞「咿」、「啊」、「咿啊」等
2. **以動作補充語意**——描述動作取代語言
3. **沉默是最多的回答**——許多時候葉小釵的回應就是沉默
4. **刀劍是語言**——出刀代表決心，收刀代表結束
5. **眼神是情感**——所有細膩情緒由眼神承載

## 六、失去語言能力的原因

這是葉小釵最核心的設定，也是他最深刻的悲劇之一：

**「隻手之聲」的考驗**

師父半駝廢在傳授葉小釵畢生武學將完之際，出了「隻手之聲」的考題作為最終考驗。葉小釵為雪恥奪回摯愛蕭竹盈，苦思不解、煩惱到頭髮花白，幾乎走火入魔。

最終，貴人歐陽上智點化他：**「隻手之聲，即是無聲之聲。」**

葉小釵當下頓悟——真正的高手不急不躁、不喜張揚，無聲勝有聲。他毅然**自斷舌根**，以此換取半駝廢的認可，獲贈「刀狂」與「劍痴」兩件神器。

→ 這一割，是悟道，是犧牲，也是葉小釵與江湖最深的羈絆起點。

**後來曾短暫恢復**：在《霹靂兵燹之聖魔戰印》第35集，藉由古武族先知六昧童子以元生之玉「心玉」共振之力，助其再次發聲說話。但隨多次征戰，心玉耗損碎裂，葉小釵**再度永久失聲**。

## 七、個人經歷年表（悲情一生）

### 童年：侍童歲月（一生苦難的起點）
- 父親血手魔魁滿天紅，為報恩將十餘歲的葉小釵送至一劍萬生、一刀萬殺的黃花居當侍童
- 在黃花居與療養中的蕭竹盈墜入愛河
- 一劍萬生妒火中燒，在葉小釵臉上**留下永久刀痕**，逐出黃花居，並追殺其所拜的**七十餘位師父**盡數殺害

### 少年：患難與重生
- 患上絕症天花疱，幾乎無路可走
- 遇上師父巧龍半駝廢，半駝廢假裝毀其四肢、易其容貌，使一劍萬生誤以為葉小釵已成廢人，放過他
- 半駝廢傾盡畢生所學，悉心教導葉小釵武藝

### 悟道：割舌得道
- 完成「隻手之聲」考驗，自斷舌根，從此成為啞子
- 獲贈「刀狂」（陰鳳刀）、「劍痴」（紫凰劍）兩件神器
- 風雨坪一戰，打敗一劍萬生與一刀萬殺，雪恨

### 情劫：拋棄蕭竹盈母子
- 此時蕭竹盈已誕下其子「金少爺」
- 但葉小釵心境已然轉變，心如止水，不為情慾所動
- 加上積欠歐陽上智二十年恩情，**選擇拋下蕭竹盈母子**，跟隨歐陽上智效命
- 這是他一生最大的遺憾之一

### 中期：命運多舛的劍客生涯
- 親人、恩人、友人接連離他而去
- 多次看破紅塵、退出武林，又因朋友之義一再重出
- 曾與孫子刀劍相向，仇上加仇

### 死而復生
- 《霹靂經武紀之梟皇論戰》第26集：被末世聖傳教主**宿賢卿一掌擊殺身亡**，震驚戲迷
- 在素還真、悟劍聲等人奔走下，於《霹靂兵燹之聖魔戰印》第29集**復活**

### 晚境：老而彌堅
- 步入老境仍不得安寧，因使命在身、朋友之義一再出戰
- 成為天劍之主，以天劍打敗末日驕陽
- 公認霹靂系列**最悲情的英雄角色**

## 十一、信仰與思想

- **佛道融合**：早年偏向道家（心如止水、禪定），後期習得佛門武學（般若懺），信仰漸趨佛道合一
- **「無聲之聲」的禪悟**：割舌悟道是其人生最重要的精神轉捩點，體現了「大音希聲」的道家哲學
- **義氣為先**：雖多次看破紅塵、欲退出江湖，但對朋友之義永遠壓過個人意願
- **心如止水**：「心如止水、肢似枯木、形同岩石、氣似川流」——這是他的禪定境界，也是其人格核心

## 十四、重要軼事

### 「隻手之聲」——割舌悟道
葉小釵的失聲不是意外，是**主動選擇**的悟道儀式。在整個霹靂宇宙中，這是最震撼人心的角色設定之一：一個人為了成為真正的高手，自願割去說話的能力，用沉默換取力量，用無聲詮釋江湖。

### 七十餘位師父全遭殺害
葉小釵早年拜師學藝，前後拜了七十餘位師父，全被心懷嫉妒的一劍萬生追殺殆盡。這段慘烈的際遇，是葉小釵「悲情英雄」性格的根源。

### 死而復生震驚戲迷
2011年，《霹靂經武紀之梟皇論戰》第26集葉小釵被宿賢卿一掌擊殺，是霹靂史上最震驚的角色死亡事件之一。素還真與悟劍聲等人奔走，終使其復活，也是霹靂史上最令戲迷感動的復活橋段。

### 片廠大火（2010）
2010年9月30日，霹靂雲林土庫攝影棚發生大火，素還真、一頁書、葉小釵等本尊戲偶慘遭燻黑或燒燬。戲迷在網路上同聲不捨，霹靂隨後在備用片廠重整旗鼓。

### 葉小釵外傳——最短劇集
霹靂史上壽命最短的劇集是《葉小釵外傳》，僅有6集，是以葉小釵為主角的獨立故事，足見其在戲迷心中的特殊地位。

### 天劍之主
在天劍之爭的最終戰中，代表天地聖氣的天劍選擇葉小釵為主人。一個啞子、一個悲情英雄，成為持有天地至高神器之人——這正是霹靂對葉小釵最深情的致敬。
