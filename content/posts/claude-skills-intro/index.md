最近在玩 Claude 的 Skill 功能，做了八個台灣在地角色包。霹靂三台柱素還真、葉小釵、一頁書，三口組秦假仙、蔭屍人、業途靈，加上大魔頭鬼王棺，還有秀場天王豬哥亮。裝上去之後，Claude 就會用他們各自的風格回話——素還真自稱「劣者」說話帶江湖哲理；葉小釵只能用「咿」「啊」配動作表達；一頁書開口就是「邪魔歪道，死有餘辜！」；秦假仙「哎呀！」掛嘴邊；蔭屍人遇事必喊「阿爸餵～」；業途靈「哼！」開頭句末「咧」；鬼王棺每句話收尾都加「吶」，慢條斯理帶著壓迫感；豬哥亮一口台語腔草根到底。說話方式不一樣，角色的靈魂就完全不同。

八個 Skill 都打包好了，直接下載安裝就能用，不用自己設定。參考資料也放在這頁，有需要可以直接查閱。

📥 [下載 Skills Bundle（ZIP）](./skills-bundle.zip)

## 霹靂布袋戲

| 檔案 | 角色 | 特色 |
|------|------|------|
| `su-huanzhen-skill-v2.skill` | 素還真（清香白蓮） | 自稱「劣者」，文言江湖哲理 |
| `ye-xiaochai-skill-v2.skill` | 葉小釵（刀狂劍痴） | 只說「咿」「啊」，動作放最後 |
| `yi-ye-shu-skill.skill` | 一頁書（百世經綸） | 「邪魔歪道，死有餘辜！」 |
| `qin-jiaxian-skill.skill` | 秦假仙（天下第一辯） | 「哎呀！」開頭，句末「啦」「嘛」 |
| `yinshi-ren-skill.skill` | 蔭屍人（千邪洞之主） | 受驚必喊「阿爸餵～！」 |
| `ye-tuling-skill.skill` | 業途靈（三途判） | 「哼！」開頭，句末「咧」 |
| `gui-wang-guan-skill.skill` | 鬼王棺（狡突臉） | 句句收尾加「吶」 |
