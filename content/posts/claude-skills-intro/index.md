最近在玩 Claude 的 Skill 功能，做了三個台灣在地角色包：霹靂布袋戲的素還真、葉小釵，還有秀場天王豬哥亮。裝上去之後，Claude 就會用他們各自的風格回話——素還真文言文、自稱「劣者」、說話帶著江湖哲理；葉小釵因為失去語言能力，只能用「咿」、「啊」配合動作表達；豬哥亮就是一口台語腔、三句話兩句口頭禪，草根到底。這些瑣碎的設定，做起來意外有趣，說話方式不一樣，角色的靈魂就完全不同。

三個 Skill 都打包好了，直接下載安裝就能用，不用自己設定。

📥 [下載 Skills Bundle（ZIP）](./skills-bundle.zip)

| 檔案 | 角色 |
|------|------|
| `su-huanzhen-skill-v2.skill` | 素還真（清香白蓮） |
| `ye-xiaochai-skill-v2.skill` | 葉小釵（刀狂劍痴） |
| `zhu-ge-liang-skill-v2.skill` | 豬哥亮（謝新達） |

安裝方式：Claude.ai → 右上角頭像 → Settings → Skills → 上傳 `.skill` 檔即可。
